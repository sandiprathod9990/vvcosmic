# How to Edit VVCosmic.com

All website content, pricing, services, contact info, and SEO settings are controlled from one file.

## Main config file (edit this first)

**`config/site-data.js`**

| Section | What you can change |
|---------|---------------------|
| `site` | Phone, email, location, domain, tagline, practitioner name |
| `seo.home` | Google title, description, keywords for homepage |
| `seo.booking` | SEO for booking page |
| `services` | Astrology, Numerology, Vastu, Palmistry, Tantra — names, descriptions, features |
| `testimonials` | Client reflection quotes (no pricing on site) |

After editing, restart the server:

```bash
npm start
```

---

## Backend structure

```
server.js              ← Routes, API, booking form handler
config/site-data.js    ← ALL content & pricing (edit here)
views/
  index.ejs            ← Homepage layout (HTML structure)
  booking.ejs          ← Booking page layout
  partials/seo-head.ejs ← Meta tags, Open Graph, Google schema
public/
  css/styles.css       ← Colors, fonts, layout
  js/main.js           ← Navigation, scroll animations
  js/booking.js        ← Multi-step booking form
```

## Consultation inquiries

The site does not display pricing. Inquiries use `/booking` with fields: Name, Country, Email, WhatsApp, Area of Concern, Message. Edit copy in `views/booking.ejs` and `config/site-data.js`.

---

## Change homepage text

- **Quick changes:** Edit `config/site-data.js` (services, SEO text)
- **Layout/sections:** Edit `views/index.ejs`
- **Colors/fonts:** Edit `public/css/styles.css` (top `:root` section)

---

## Booking inquiries (backend API)

When someone submits the booking form:

- **POST `/api/inquiry`** — saves inquiry (currently in memory)
- **POST `/api/inquiry`** — consultation inquiry (fields: name, country, email, whatsapp, concern, message)

To persist inquiries to a file or email, edit `server.js` around line 90.

---

## SEO files (automatic)

- **Sitemap:** `https://vvcosmic.com/sitemap.xml` (generated by server)
- **Robots:** `https://vvcosmic.com/robots.txt` (generated by server)
- **Schema markup:** In `views/partials/seo-head.ejs` (Person + ProfessionalService)

Update `site.domain` in config when going live.
